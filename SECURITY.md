# Security policy

Please do not post credentials, private traces, or vulnerability details in a
public issue. To report a security concern, use [GitHub's private vulnerability
reporting](https://github.com/dmoliveira/coding-agent-observability/security/advisories/new).
If that option is unavailable, contact the repository owner privately instead.

AI Observatory stores sensitive agent traces and instance secrets. Review the
[security and privacy guide](docs/security.md) before enabling tracing, sharing
the server, or storing backups.
