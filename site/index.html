01 / THE IDEA

Less black box.
More understanding.

When agents move quickly, the interesting details can disappear. Keep the context you need to understand what happened—without giving up control of where the traces live.

◎

01 / OBSERVE

Follow the full flow

02 / OWN

Keep it close

Self-host the observability stack on macOS or Linux. Its browser-facing ports bind to localhost by default.

↗

03 / CONNECT

Share deliberately

Connect OpenCode once for your user. Reach the dashboard from a permitted Tailscale device only when you opt in.

✳

Private-first is not secret-free. Traces can contain prompts, source code, reasoning, and credentials. Model-provider traffic is separate and may leave your machine. Read the security guide →

02 / THE SETUP

A small setup.
A clearer picture.

Start the local stack, connect OpenCode, and follow the work in Langfuse. The detailed guide covers credentials, backups, and optional private sharing.

01

Start the local stack

Clone the repository and run setup with Docker and Compose.

make setup && make up
02

Connect OpenCode

Create a Langfuse project key, then connect it once for your user.

make connect-opencode-global
03

Follow the trace

Open the dashboard and inspect the sessions and tool activity you chose to record.

make open
